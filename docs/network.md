```text

```

```text

```


## 2. IPv4 Configuration

The VM currently receives its IPv4 address through DHCP.

Current address:

```text
192.168.11.245/24
```

The persistent network configuration is:

```text
auto enp0s3
iface enp0s3 inet dhcp
```

Therefore, the project does **not** require a static IP address.

The address:

```text
192.168.11.245
```

must not be hard-coded into the `add-vm` provisioning because it is dynamically assigned by DHCP.

## 3. IPv6 Configuration

The interface uses automatic IPv6 configuration:

```text
iface enp0s3 inet6 auto
```

The current link-local IPv6 address is:

```text
fe80::9d1f:b4fd:87d5:8b26/64
```

This address is dynamically generated and must not be reproduced as a fixed value.

## 4. Routing

The current default route is:

```text
default via 192.168.11.1 dev enp0s3 proto dhcp src 192.168.11.245 metric 1002
```

Therefore:

```text
Interface:     enp0s3
Gateway:       192.168.11.1
Source IPv4:   192.168.11.245
Configuration: DHCP
```

The connected network is:

```text
192.168.11.0/24
```

The gateway and IP address are DHCP-provided and should remain dynamic in the rebuilt VM.

## 5. DNS

The current resolver configuration is:

```text
domain Home
nameserver 192.168.11.1
nameserver fe80::e01:4bff:fe70:2f10%enp0s3
```

`/etc/resolv.conf` is generated by `dhcpcd` from the DHCP configuration:

```text
# Generated by dhcpcd from enp0s3.dhcp, enp0s3.ra
```

Therefore, the DNS server should not be hard-coded into the provisioning.

The rebuilt VM should obtain its DNS configuration dynamically from the network.

The active/enabled Debian network service is:

```text

```

The persistent configuration is stored in:

```text
/etc/network/interfaces
```

The relevant configuration is:

```text

iface lo inet loopback

auto enp0s3
iface enp0s3 inet dhcp

iface enp0s3 inet6 auto
```

There are currently no additional configuration files in:

```text
/etc/network/interfaces.d/
```

and:

```text

```

is empty.

## 7. What Must Be Reproduced

For `add-vm`, the important network behavior to reproduce is:

```text
enp0s3
   ↓
IPv4 DHCP
   ↓
IPv6 automatic configuration
```

The following values are **dynamic** and must not be copied as fixed configuration:

```text
192.168.11.245       ← current DHCP address
192.168.11.1         ← current DHCP gateway
192.168.11.1         ← current DNS server
fe80::...            ← current link-local IPv6 address
```

The network configuration itself is what must be reproduced.
